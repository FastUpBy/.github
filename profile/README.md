# FastUp — маркетинговое агентство из Беларуси

Настраиваем и ведём рекламу, продвигаем сайты в поиске и у нейросетей (SEO и GEO),
разрабатываем сайты. Работаем удалённо по всей Беларуси: под каждый проект собираем
специалистов с многолетним опытом, которые нужны именно в этой задаче.

Часть рутины у нас забирает собственный ИИ-агент, встроенный в CRM студии. Он поднимает
историю клиента, готовит документы и находит то, что менеджер мог пропустить. Клиенту это
даёт больше скорости и внимания к проекту за ту же цену.

## MicroApps.by — наш открытый код

[MicroApps.by](https://microapps.by) — платформа лёгких веб-инструментов, которую мы
написали с нуля на чистом PHP 8.3, без базы данных и без тяжёлого фреймворка. Репозиторий
[microapps.by](https://github.com/FastUpBy/microapps.by) в этой организации — исходный код
платформы в открытом доступе.

Мы строили платформу под SEO с первого дня, без единого рубля на рекламу. Сейчас это около
1500 органических визитов в месяц из Яндекса и Google.

Тот же подход работает и в клиентских проектах. На сайте [kubdekor.by](https://kubdekor.by)
SEO было заложено в архитектуру с самого начала: клиент, который сам профессионально
занимается поисковой оптимизацией, предложил выкупить его целиком, без единой правки.
